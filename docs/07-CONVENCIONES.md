# 07 - Convenciones de Código y Trabajo

## Nomenclatura
* **Archivos y Carpetas**: `kebab-case` (ejemplo: `detalle-servicio.js`).
* **Componentes React**: `PascalCase` (ejemplo: `CardCoach.jsx`).
* **Variables y Funciones**: `camelCase` (ejemplo: `obtenerServicios()`).
* **Constantes y Variables de Entorno**: `UPPER_SNAKE_CASE` (ejemplo: `DATABASE_URL`).

## Idioma del Código
* **Código y Variables**: Inglés (`const userRole = 'Coach'`).
* **Comentarios y Documentación**: Español.

## Formato de Commits (Git)
* `feat:` Para nuevas funcionalidades (ejemplo: `feat: agregar filtro por juegos`).
* `fix:` Para corrección de errores (ejemplo: `fix: corregir horario de reservas`).
* `docs:` Para cambios en la documentación (ejemplo: `docs: actualizar IDENTIDAD-MARCA`).
