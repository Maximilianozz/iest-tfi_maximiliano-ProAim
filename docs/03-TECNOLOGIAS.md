# 03 - Tecnologías del Proyecto

## Stack Tecnológico Elegido

| Área | Tecnología Elegida | Justificación |
| :--- | :--- | :--- |
| **Frontend** | React + Next.js | Permite crear una interfaz súper fluida, rápida e interactiva, ideal para un e-commerce moderno. |
| **Estilos** | Tailwind CSS | Facilita la aplicación rápida de la paleta de colores de la marca (#00F0FF, #7000FF, #0D0E12). |
| **Base de Datos** | PostgreSQL | Permite estructurar relaciones complejas entre usuarios, coaches, reservas y pagos. |
| **Repositorio** | GitHub | Facilita el control de versiones del código y la colaboración estructurada. |
| **Publicación** | Vercel | Excelente integración nativa con Next.js que asegura despliegues rápidos e infraestructura confiable. |
| **IA Asistente** | ChatGPT / Gemini | Utilizadas para la redacción de especificaciones, optimización de textos y soporte en código. |

## Fundamentación
Mantenemos la arquitectura moderna basada en Next.js y PostgreSQL porque ofrece el mejor equilibrio entre rendimiento, escalabilidad para una plataforma de e-sports y rapidez de desarrollo.
