# 02 - Requerimientos del Sistema

## Requerimientos Funcionales (RF)

| Código | Descripción | Prioridad |
| :--- | :--- | :--- |
| **RF01** | Catálogo interactivo de servicios de coaching con filtros por videojuego y rol. | Alta |
| **RF02** | Formulario de reserva de turnos con calendario para sesiones de coaching. | Alta |
| **RF03** | Registro y autenticación de usuarios (alumnos y coaches). | Alta |
| **RF04** | Panel de usuario para visualizar sesiones reservadas y retroalimentación recibida. | Media |
| **RF05** | Integración de pasarela de pago para la compra de servicios. | Alta |
| **RF06** | Sistema de calificación y reseñas sobre los coaches. | Baja |

## Requerimientos No Funcionales (RNF)
* **RNF01 (Rendimiento):** Tiempo de carga inicial inferior a 2 segundos en conexiones estándar.
* **RNF02 (Usabilidad):** Interfaz oscura optimizada (Dark Mode) adaptada a dispositivos móviles y escritorio.
* **RNF03 (Seguridad):** Encriptación de contraseñas de usuario e integración segura de pasarelas de pago.
* **RNF04 (Disponibilidad):** La plataforma debe garantizar una disponibilidad del 99.5% online.
